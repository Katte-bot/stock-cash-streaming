# A股防御型量化策略增强研究方案

- 版本：v1.0
- 整理日期：2026-10-22
- 用途：交给 DeepSeek / AI IDE，基于现有回测程序继续实现与验证
- 定位：A股防御型选股与组合研究，不直接自动下单
- 收益研究目标：在当前约 8% 年化收益的历史基线之上，探索接近 12% 的可重复结果
- 重要声明：12% 是研究目标，不是收益承诺。本文新增的权重、行业池、参数均是待验证假设，不是已证明有效的结论。

## 1. 背景与当前策略基线

已经对电网设备与天然气相关股票池开展过 2018—2026 年回测，当前策略据报告年化收益约 8%。实施前必须用代码重现基线，并审计复权、分红、费用、滑点、成交假设、停牌、涨跌停、历史 ST 与退市处理、幸存者偏差及波动率目标的实际实现。

### 1.1 当前因子权重

| 因子 | 权重 |
|---|---:|
| 低波动 | 20% |
| 非流动性 | 18% |
| 低彩票特征 | 17% |
| 低换手 | 13% |
| 低成交额 | 11% |
| 弱动量 | 9% |
| 换手波动 | 6% |
| 布林低位 | 6% |
| **合计** | **100%** |

### 1.2 当前组合规则

- 选股：Top 12。
- 权重：逆波动率，即 `w_i ∝ 1 / volatility_i`。
- 调仓：月频。
- 流动性过滤：成交额 > 1 亿元；需确认采用单日值还是过去 N 日均值。
- 排除 ST；需核实历史 ST 状态、退市股票、停牌及上市时间不足问题。
- 波动率目标：25%，高波动时自动降仓。必须检查在低波动时是否放大仓位、总敞口是否可能超过 100%。
- 已观察到电网设备与天然气股票池的历史效果好于曾测试的高流动性策略。

### 1.3 首先需要验证的疑点

1. 非流动性、低换手、低成交额可能重复计分，三者合计占 42%。
2. 缺少显式的财务质量、现金流质量、估值和股息可持续性因子。
3. 收益可能部分来自行业本身，而非选股因子。
4. Top 12、逆波动率加权、月频调仓和 25% 波动率目标可能影响收益/回撤。
5. 如果 AI 已反复用 2018—2026 全区间搜索参数，这段区间不能再被简单视为完全独立的样本外测试集。

## 2. 研究目标与成功标准

目标是探索净年化收益接近或超过 12% 的方案，同时守住防御型策略的风险特征。禁止为了达到 12% 而无约束提高仓位、加杠杆、忽略成本，或只挑历史最优参数。

任何候选策略都必须同时评估：
- 净年化收益与各自然年收益；
- 年化波动率、最大回撤、Sharpe、Calmar；
- 换手率、成本后收益和流动性；
- 单股与行业收益贡献；
- 样本内/样本外差异；
- 对参数轻微变化的稳定性；
- 是否优于原始策略和合理基准。

不能只凭年化收益排序。如果 12% 仅在反复调参的历史区间实现、样本外失效，不应视为成功。

## 3. 研究流程

严格按顺序实施，避免同时改动多个关键维度：

1. 复现基线并审计回测可信度。
2. 做因子相关性、分组收益与消融实验。
3. 单独测试财务质量、现金流质量、估值、股息可持续性。
4. 对比行业池与行业中性化方案。
5. 测试持仓数、权重、调仓规则。
6. 测试波动率目标与市场状态过滤。
7. 对少量候选策略做滚动前推和样本外验证。
8. 保存全部实验，包括失败结果。

## 4. 第一轮：因子审计与消融

### 4.1 必须输出的分析

对每个因子计算缺失率、分布、异常值、因子相关性、下一期收益关系、分组收益、按年份/行业/市场状态的表现、单因子组合表现，以及删除该因子后的边际变化。明确公式、窗口、标准化方式和分数方向。

建议统一使用横截面排名或稳健标准化，保证分数越高越符合目标特征。对低流动性股票，必须评估冲击成本和成交可实现性。

### 4.2 实验矩阵

| ID | 实验 | 主要问题 |
|---|---|---|
| A0 | 原策略复现 | 基线能否重现？ |
| A1 | 去掉低成交额因子 | 是否与其他流动性因子重复？ |
| A2 | 去掉低换手因子 | 是否提供独立贡献？ |
| A3 | 去掉非流动性因子 | 真实边际收益与交易成本如何？ |
| A4 | 合并非流动性、低换手、低成交额为一个流动性组 | 是否减少重复计分？ |
| A5 | 去掉布林低位 | 短期择时是否有长期独立价值？ |
| A6 | 去掉换手波动 | 是否有增量信息？ |
| A7 | 行业中性化与非中性化对比 | 收益来自行业还是个股选择？ |

额外测试流动性组总权重 20%、25%、30%，并与原始 42% 做比较。仅将它们合并不代表一定更好，必须用增量收益与风险结果判断。

## 5. 第二轮：防御增强版因子

### 5.1 待测试的起始权重

这是一组实验初值，不是已验证的最优配置。

| 因子 | 原策略 | 防御增强版 |
|---|---:|---:|
| 低波动 | 20% | 20% |
| 低彩票特征 | 17% | 14% |
| 非流动性 | 18% | 10% |
| 低换手 | 13% | 8% |
| 低成交额 | 11% | 0%（不单独计分） |
| 财务质量 | 0% | 15% |
| 现金流质量 | 0% | 10% |
| 估值 | 0% | 8% |
| 股息可持续性 | 0% | 6% |
| 弱动量/中期趋势 | 9% | 4% |
| 布林低位/短期反转 | 6% | 3% |
| 换手波动 | 6% | 2% |
| **合计** | **100%** | **100%** |

### 5.2 新因子的可解释定义

**财务质量 15%：**
- ROE 或 ROIC 的水平与稳定性；
- 经营现金流 / 净利润；
- 利润率或营业利润稳定性。
- 子因子可从 40% / 30% / 30% 起步，作为实验初值；需考虑行业特征和极端值。

**现金流质量 10%：**
- 经营现金流与净利润的匹配程度；
- 自由现金流稳定性；
- 应收账款/合同资产增速与收入增速差异；
- 现金流对资本开支、利息和股息的覆盖能力。

**估值 8%：**
- 盈利收益率或适用的 PE；
- PB；
- 自由现金流收益率；
- 对特定行业可研究 EV/EBITDA。
- 必须按行业或商业模式做适当比较，避免把周期性高盈利时期的低 PE 当作便宜。

**股息可持续性 6%：**
- 过去 3 年分红连续性；
- 股息 / 自由现金流；
- 派息率是否异常；
- 负债与资本开支对分红的压力。
- 高股息率本身并不是质量指标，要防止利润下滑或股价大跌造成的股息陷阱。

### 5.3 财报数据时点（强制）

必须使用 point-in-time 数据：财务报表只能从实际公告日之后影响选股。不能把后来发布的年报或修订数据提前填入历史时点。存储报告期、公告日期和数据版本。对财报修订和追溯调整要有明确规则。

### 5.4 实验矩阵

| ID | 实验 |
|---|---|
| B0 | 原策略 |
| B1 | 原策略 + 财务质量 |
| B2 | 原策略 + 现金流质量 |
| B3 | 原策略 + 估值 |
| B4 | 原策略 + 股息可持续性 |
| B5 | 完整防御增强版 |
| B6 | 防御增强版 + 行业内排名 |

每次先单独测试新增因子的增量，再组合；如果因子没有独立贡献，应允许否决它，不能为了追求 12% 强行保留。

## 6. 第三轮：行业池拓展

这些行业是候选研究池，不是直接买入建议。应尽量恢复历史可投资股票，不要只使用当前仍上市的股票。

| 优先级 | 行业池 | 研究逻辑 | 主要风险字段 |
|---|---|---|---|
| A | 电网设备、输配电、配电自动化、电力自动化 | 电网投资、设备更新和订单 | 订单质量、应收账款、现金流、毛利率、估值、客户集中度 |
| A | 水电、核电、电力公用事业 | 运营现金流和分红可能与防御因子互补 | 资本开支、负债、政策、电价、股息覆盖 |
| A- | 天然气城燃、管网、储运 | 现金流、估值与股息研究 | 气源价、顺价能力、需求、应收款、资本开支 |
| A- | 水务、污水处理 | 需求及运营模式可能相对稳定 | 应收款、项目回款、融资成本、资本开支 |
| B | 高速公路、港口、铁路 | 成熟资产、现金流和分红 | 运量/货运周期、贸易、特许经营期限、扩建支出 |
| B | 通信运营 | 运营现金流和股息候选 | 资本开支、竞争、监管和业务转型 |
| B | 部分银行 | 估值与股息研究 | 资产质量、信用风险、拨备和利率变化 |

### 6.1 行业池实验

| ID | 股票池 |
|---|---|
| C0 | 现有电网设备 + 天然气 |
| C1 | 全 A 股可投资股票池 |
| C2 | 电网设备 + 燃气 + 电力公用事业 + 水务 |
| C3 | C2 + 高速公路、港口、铁路、通信运营 |

每个股票池对比：
- 不做行业中性化；
- 行业内排名选股；
- 行业中性化评分后全市场选股；
- 单行业权重上限。

同时报告各行业贡献、各股票贡献和行业集中度。若去除行业暴露后超额收益消失，应如实指出策略很大程度上依赖行业配置；若仍存在，才更支持选股因子有独立价值。

可将行业基本面过滤作为独立实验，例如检查电网企业应收账款、燃气企业顺价能力、公用事业负债和交通运营企业资本开支。阈值只允许用研究区间设定，再固定做验证。

## 7. 第四轮：组合构建

### 7.1 持股数量

固定评分，比较 Top 12（当前）、Top 20、Top 30。报告净收益、回撤、行业/单股集中度、换手率和收益是否依赖少数赢家。

### 7.2 权重

比较：
1. 等权；
2. 当前逆波动率权重 `w_i ∝ 1 / vol_i`；
3. 逆波动率 + 单股权重上限；
4. 逆波动率 + 行业权重上限。

初始敏感性参数：
- 单股上限：8%、10%、12%；
- 行业上限：25%、30%、35%。

这些是实验参数。上限截断后要重新规范化权重，确保总敞口定义一致。

### 7.3 再平衡

对比月频完全重建（当前）、缓冲区规则、双月调仓、季度调仓。

缓冲区实验可设为：已有持仓跌出前 18 名才卖出，新候选进入前 12 名才买入。报告每笔交易原因、换手率、费用和成交假设。

### 7.4 成交额过滤

当前 > 1 亿元的口径必须明确。建议比较过去 20 日平均成交额、过去 60 日平均成交额和当前基线门槛。不能只看单日成交额；应考虑订单金额相对成交额的冲击成本。

## 8. 第五轮：风险控制

### 8.1 审查 25% 波动率目标

需要从代码明确：
- 波动率估计窗口；
- 估计组合波动还是单股波动；
- 是否考虑股票间相关性；
- 何时降仓，低波动时是否加仓；
- 总敞口是否可能超过 100%；
- 对波动率跳升和估计滞后的处理方式。

防御型第一版建议测试“不加杠杆、只在风险上升时降仓”的规则，不应未经单独验证就因为实际波动低于目标而自动借助杠杆放大仓位。

### 8.2 风险参数实验

| ID | 波动率目标 | 限制 |
|---|---:|---|
| E0 | 当前 25% | 原实现，必须完整复现 |
| E1 | 12% | 只减仓，总敞口不超过 100% |
| E2 | 15% | 只减仓，总敞口不超过 100% |
| E3 | 18% | 只减仓，总敞口不超过 100% |
| E4 | 20% | 只减仓，总敞口不超过 100% |

上述参数不是推荐的最优风险目标，需结合组合真实波动率分布判断。

### 8.3 市场状态过滤

比较不择时、指数低于 200 日均线时股票仓位降至 70%、以及仅在市场波动率高于训练区间历史高分位时降仓。

信号以当日收盘数据生成时，最早应在下一可交易时点执行，不能同一收盘价既生成信号又假定无摩擦成交。市场过滤的效果必须样本外检验，不能预设一定降低回撤或提高收益。

限制搜索自由度，建议分轮完成，不要一次进行巨大参数网格搜索。

| 轮次 | 建议组数 | 内容 | 主要交付 |
|---|---:|---|---|
| 第 0 轮 | 2–3 | 基线复现、费用与成交规则审计 | 基线审计 |
| 第 1 轮 | 6–8 | 因子消融、流动性组合、行业中性化 | 因子贡献报告 |
| 第 2 轮 | 6–8 | 质量、现金流、估值、股息因子 | 增强因子报告 |
| 第 3 轮 | 8–10 | 行业池、持股数、权重、调仓缓冲 | 组合构建报告 |
| 第 4 轮 | 4–6 | 波动率目标与市场过滤 | 风险比较报告 |

若早期实验表明新因子没有独立贡献，应停止扩展；不要为凑足实验数量而继续调参。

## 10. 回测可信度要求（强制）

### 10.1 成本与可交易性

处理或明确披露：
- 买卖手续费；
- 卖出印花税，使用对应历史日期的费率规则；
- 过户费及其他适用成本；
- 滑点与市场冲击；
- 涨跌停时无法按理想价格成交；
- 停牌、退市整理和不可交易股票；
- 分红、拆分、送转与复权；
- 上市时间不足的新股；
- 历史 ST 状态与退市股票；
- 信号形成时间到实际成交时间的差异。

缺少可靠历史数据时应说明限制，并做保守的成本敏感性测试。

### 10.2 前视和幸存者偏差

- 因子只能使用决策时已知的数据。
- 财报从实际公告日之后生效。
- 收盘产生的信号不能假定同一收盘价执行。
- 尽可能使用历史可投资股票池，纳入历史退市股，避免只用目前存续股票。
- ST 过滤应基于历史状态，而不是当前状态。
- 如果使用缠论分型、笔或中枢，必须以信号真正确认时点参与回测，不能把图上的回画位置当作信号已提前可知。

### 10.3 过拟合与多重检验

- 保存所有尝试，包括失败结果。
- 记录每次实验的参数、数据范围和代码版本。
- 检查参数附近的小幅变化是否导致结果崩溃。
- 限制搜索范围，对大量检验进行适当的多重检验控制。
- 同时关注经济效应、置信区间、样本量、交易成本和样本外结果。
- 最终测试区间冻结后，不得再根据其表现修改参数。

### 10.4 时间顺序验证

采用研究集、参数确认集、独立测试集和滚动前推测试。若 2018—2026 全区间此前已用于多轮搜索，就不能把其中任意年份简单称为完全未见的测试集。通过滚动前推模拟每个月的真实决策；每个时点的参数仅由当时之前的数据决定。

## 11. 统一报告指标

每个实验必须输出：
- 净年化收益、净值曲线；
- 年化波动率、最大回撤、回撤持续时间；
- Sharpe、Sortino、Calmar 及其计算约定；
- 自然年收益和月度收益分布；
- 胜率、平均盈利、平均亏损；
- 换手率、交易成本总额、成本占毛收益比例；
- 市场敞口时间、单股贡献、行业贡献；
- 样本内与样本外差异；
- 与原始策略、等权组合和适当基准的对比。

每个结果必须附带实验 ID、代码版本、参数配置、数据源、数据截止时间、股票池定义、信号/成交假设、成本设置和限制说明。

比较表模板：

| 实验 ID | 股票池 | 因子版本 | 持股数 | 权重方法 | 调仓 | 年化净收益 | 波动率 | 最大回撤 | Sharpe | Calmar | 换手率 | 样本外表现 |
|---|---|---|---:|---|---|---:|---:|---:|---:|---:|---:|---|

不要只依据年化收益排序。

## 13. 交给 DeepSeek 的实施指令

请将本文作为策略研究规格。按阶段实施，先检查和复现，不要一开始大规模搜索权重。

### 第一阶段：基线审计

1. 阅读当前项目源码、因子公式和数据流程。
2. 明确每个因子的公式、窗口、方向、标准化、缺失值处理。
3. 明确成交额门槛的定义与计算窗口。
4. 确认 25% 波动率目标的仓位规则及是否可能加杠杆。
5. 检查手续费、历史印花税、滑点、涨跌停、停牌、复权、ST、退市和交易时点。
6. 重跑当前配置并解释与用户报告的约 8% 年化差异。
7. 不修改基线生产配置；实验配置和结果隔离保存。

### 第二阶段：因子审计

生成因子相关矩阵、分组收益、消融结果、流动性因子合并实验和行业中性化对比。保存全部实验结果。

### 第三阶段：新增质量因子

依次测试财务质量、现金流质量、估值和股息可持续性，再测试完整防御增强版。严格应用公告日可见数据。

### 第四阶段：行业与组合

按 C0、C1、C2、C3 顺序比较股票池；再比较 Top 12/20/30、不同权重及调仓规则。每次只更改有限维度。

### 第五阶段：风险和最终验证

比较波动率目标、只减仓和市场过滤；对少量候选方案执行滚动前推、成本后、参数稳定性和行业贡献分析。未经验证的版本不得升级为自动实盘策略。

### DeepSeek 最终交付清单

- 基线复现与数据审计报告；
- 因子公式及财务数据时点说明；
- 实验配置文件；

## 14. 最终原则

本项目不是命令 AI 一定找到年化 12% 的参数，而是通过有纪律的实验，发现哪些条件可能具有稳定的增量价值。

实施优先级：

1. 基线重现和回测可信度审计；
2. 因子消融与流动性因子重复性分析；
3. 财务质量、现金流质量、估值与股息可持续性；
4. 电网设备、燃气及其他防御行业对比；
5. 组合权重、调仓规则和风险预算；
6. 滚动样本外验证。

**最终验收标准：** 可靠的收益来源、真实交易条件下的净收益、可接受的回撤、样本外可重复性和完整可追溯的实验记录，比单个回测区间里的最高年化收益更重要。
