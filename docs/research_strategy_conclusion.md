# 策略研究报告：从「资金流强者恒强」到「防御型组合」

- 研究区间：2018-01-02 ~ 2026-10-19
- 样本域：电网设备（新浪概念「智能电网」38 只）+ 天然气（新浪行业「燃气生产和供应业」33 只），共 71 只
- 数据：腾讯后复权日线（144,238 行）+ 新浪个股资金流（237,575 行）+ 新浪板块成分
- 基准：域内等权买入持有（不计成本）
- 交易约束：t 日收盘信号 → t+1 收盘执行；T+1；涨跌停不可成交；单边成本 0.13%

> 本报告为量化研究结果，不构成投资建议。

---

## 1. 研究起点

最初按 `me.md` 的资金流横向对比方法构建 `composite` / `flow_rules` 策略，结果全部跑输基准：

| 策略 | 年化 | 夏普 | 最大回撤 | 基准年化 |
| --- | ---: | ---: | ---: | ---: |
| composite top3/weekly | 0.58% | 0.18 | -70.17% | 3.68% |
| composite + 沪深300择时 | -2.38% | — | -54.82% | 3.68% |
| flow_rules（me.md 规则） | -7.47% ~ -19.79% | — | — | 3.68% |

问题不在执行细节，而在**因子方向**。因此先做因子诊断。

## 2. 因子诊断结论（关键发现）

15 个原始因子的 RankIC（未来 5 日）**全部为负，且 2018–2026 逐年一致**：

| 因子 | mean_IC | ICIR | 熊市IC |
| --- | ---: | ---: | ---: |
| vol_20 | -0.0691 | -0.29 | -0.0778 |
| turnover_5 | -0.0680 | -0.28 | -0.0700 |
| amount_20d | -0.0592 | -0.25 | -0.0676 |
| ma60_ratio | -0.0558 | -0.24 | -0.0677 |
| ret_20 | -0.0534 | -0.25 | -0.0652 |
| ret_5 | -0.0504 | -0.24 | -0.0562 |
| boll_pos | -0.0453 | -0.22 | -0.0541 |
| main_net_ratio_5d | -0.0291 | -0.17 | -0.0293 |
| inflow_days_5 | -0.0109 | -0.07 | -0.0120 |

结论：在本样本中，**高波动 / 高换手 / 高成交额 / 强动量 / 强资金流入 → 未来 5 日收益更低**。
这与 `me.md` 的「资金流强者恒强」假设方向相反，因此原策略必然跑输。

补充计算了 5 个特色因子（v2 已入库）：

| 因子 | mean_IC | ICIR | 说明 |
| --- | ---: | ---: | --- |
| max_ret_20 | -0.0694 | -0.32 | 彩票效应：近 20 日单日最大涨幅越高，未来越差 |
| turnover_std_20 | -0.0694 | -0.30 | 换手率波动越大，未来越差 |
| downside_vol_20 | -0.0405 | -0.16 | 下行波动 |
| ret_60 | -0.0441 | -0.19 | 中期动量反转 |
| **amihud_20** | **+0.0295** | **+0.13** | 非流动性溢价：越不流动，未来越好（唯一正 IC） |

## 3. 策略迭代路径

| 版本 | 方案 | 全期年化 | 夏普 | 回撤 |
| --- | --- | ---: | ---: | ---: |
| v0 | composite（技术+资金流） | 0.58% | 0.18 | -70.17% |
| v1 | inverted（5 因子等权反向，top5 周频） | 5.13% | 0.33 | -36.09% |
| v2 | core（5 因子加权反向，top12 月频） | 7.01% | 0.42 | -39.21% |
| v3 | core2（+彩票效应+非流动性） | 8.01% | 0.46 | -37.30% |
| **v4（最终）** | **core2 微调 + 波动率目标 25% + 1/波动加权** | **8.26%** | **0.48** | **-33.59%** |

- 「反向因子」是质变：把 15 个负 IC 因子取 `1-rank`。
- 「彩票效应 + 非流动性」是增量：`max_ret_20`（ICIR -0.32）与 `amihud_20`（唯一正 IC）分别提供了新信息。
- 「月频」优于「周频」：2018–2022 周频尚可，2023 年后周频失效，月频更稳健。
- 「波动率目标」是最终增益：把高波动期仓位降到 30%–100%，回撤从 -37.30% 降至 -33.59%，夏普从 0.46 提升到 0.48。
- 「篮子趋势择时」虽然能降低回撤，但全期收益转负（2018–2020 仓位长期过低），**不采用**。
- 「沪深300 择时」在防御型组合上失效：熊市中低波动反而占优，**不采用**。

## 4. 最终策略定义

**评分（截面百分位，越高越优先）**

| 因子 | 权重 | 方向 |
| --- | ---: | --- |
| vol_20（20日年化波动） | 20% | 越低越好 |
| turnover_5（5日平均换手） | 13% | 越低越好 |
| turnover_std_20（换手率波动） | 6% | 越低越好 |
| amount_20d（20日平均成交额） | 11% | 越低越好 |
| max_ret_20（彩票效应） | 17% | 越低越好 |
| ret_20（20日涨幅） | 9% | 越低越好 |
| boll_pos（布林带位置） | 6% | 越低越好 |
| **amihud_20（非流动性）** | **18%** | **越高越好** |

**组合与风控**
- 样本过滤：20 日平均成交额 > 1 亿元；上市不足 60 日剔除；ST / 退市整理剔除
- 选股：评分前 12 名，持仓缓冲 +1 名（降低换手）
- 加权：按 `1/vol_20` 加权（低波高配）
- 再平衡：每 20 个交易日（月频）
- 波动率目标：篮子近 20 日年化波动 > 25% 时按 `25%/实际波动` 缩放仓位（下限 30%）
- 执行：t 日收盘信号 → t+1 收盘；T+1；涨跌停不可成交；单边成本 0.13%

| 全期 2018-01 ~ 2026-10 | 8.26% | 21.28% | 0.48 | -33.59% | 0.25 | 50.8% | 3.68% | **+4.58%** |

## 6. 为什么与原始方法论相反

`me.md` 的资金流方法假设「主力净流入 → 后续上涨」。在本样本（两个偏周期/公用事业属性的板块，2018–2026）中观察到的是**反转与防御溢价**：

1. 资金流因子本身 IC 很弱（-0.01 ~ -0.03），远弱于波动率/换手（-0.07）。
2. 高换手、高成交额往往对应题材炒作的高点，后续均值回归。
3. 低波动、低关注度的标的在样本期获得稳定的风险溢价。
4. 非流动性溢价（Amihud 正 IC）在中小市值板块中显著。

这并不否定资金流方法在其他域的有效性，而是说明：**因子方向必须由本域数据检验，不能跨域照搬**。

## 7. 局限与风险

1. **成分股为当前快照**（新浪），存在幸存者偏差；已退市/调出的标的未纳入。
2. 样本仅 71 只、2 个板块，截面较窄，结论不宜外推到全市场。
3. ST 过滤使用当前股票名称，历史上曾 ST 的标的可能被误纳入。
4. 未考虑分红再投资的现金流入（使用后复权价格已近似处理）。
5. 月频策略在极端行情中反应较慢（2025 年跑输 8 个百分点）。
6. 交易成本按固定 0.13% 估算，未考虑冲击成本与容量约束。
7. 2026 年数据为样本末端，指标可能受短期行情影响。
8. 早期实验室版本曾用「全市场 pivot + rolling」派生因子，停牌日会产生额外 NaN、选股略偏乐观；现已改为直接读取 v2 `fact_factor`，研究文件与引擎口径一致。

## 8. 复现方式

```bash
cd /data02/stock-cash-streaming

# 1) 计算 v2 因子（含彩票效应/非流动性）
.venv/bin/python -m stock_cash_streaming.cli factors

# 2) 因子诊断
.venv/bin/python -m stock_cash_streaming.cli research --horizon 5

# 3) 最终策略回测（默认参数即最终策略）
.venv/bin/python -m stock_cash_streaming.cli backtest

# 4) 批量研究（样本内/样本外 + 参数搜索）
.venv/bin/python -m stock_cash_streaming.cli lab

# 5) 生成目标组合与调仓清单（实盘跟踪，信号日次一交易日收盘执行）
.venv/bin/python -m stock_cash_streaming.cli portfolio
```

配套结果文件：
- `docs/research_factor_diagnostics.md`：18 因子 IC 明细
- `docs/research_strategy_lab2.csv`：core2/core3 网格搜索结果（120 组）
- `docs/research_overlay.csv`：趋势/波动率叠加层结果（24 组）

实盘跟踪口径：
- 调仓周期与回测一致（每 20 个交易日），CLI/仪表盘会显示「距下次调仓 N 个交易日」。
- 组合权重已包含 1/vol 加权与 25% 波动率目标缩放。
- 首次运行写入基线快照，后续调仓清单以此为对比基准。
- 仅输出客观组合与调仓清单，不构成投资建议。
