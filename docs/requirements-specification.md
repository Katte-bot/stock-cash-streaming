## 1. 引言

### 1.1 编写目的
本文档描述「A股板块资金流横向对比与轮动量化系统」的**业务目标、功能需求、数据需求、非功能需求与验收标准**，作为后续设计、开发、测试与验收的基线。读者对象：产品/需求方、架构师、开发工程师、测试人员、运维人员。

### 1.2 项目背景
`me.md` 提出以**资金流横向对比**作为策略切入点：在同一板块内比较各股票的资金流入强度，寻找「主力资金持续流入但股价尚未充分反应」的标的；并从行业层面做**板块间资金轮动对比**。实证要点：

- 超大单**主动**净买入额的月度 RankIC 均值 **6.83%**，优于超大单净买入额（4.96%）；小单主动净买入 RankIC 为 **-3.02%**（散户资金为反向指标）。
- 中银量化「机构单趋势强度因子」相对行业等权基准年化超额 **10.16%**，叠加尾盘资金因子后提升至 **11.84%**。
- 「情境-特征」IRCF 因子 2017 年以来多空年化 **25.8%**、多头超额 **9.6%**、月度 IC 均值 **7.1%**、IC 胜率 **85%**。

本项目将该方法论落地为一套**可采集、可回测、可增量更新、可实时预测、可视化精美**的本地化系统，聚焦 A股 **电网设备** 与 **天然气** 两大板块。

### 1.3 名词、术语与缩略语

| 术语 | 说明 |
| --- | --- |
| 超大单/大单/中单/小单 | 按单笔成交金额或股数划分的成交档位，代表不同资金属性 |
| 主力资金 | 超大单 + 大单 |
| 机构单 | 中单 + 大单（`me.md` 定义口径） |
| 主动买入 | 以卖一价及以上成交的买盘（主动吃货），区别于被动挂单买入 |
| 净流入 | 主动买入额 − 主动卖出额 |
| 资金流强度 | 净流入 / 当日成交额 |
| RankIC | 因子值排序与未来收益排序的等级相关系数 |
| IC 胜率 | IC 为正的期数占比 |
| 拥挤度 | 板块成交额/换手率相对历史的百分位，衡量交易拥挤 |
| 中性化 | 剔除行业、市值等暴露，控制特异性偏差 |
| 增量拉取 | 仅拉取自上次水位之后的新数据，去重入库 |
| 回测 | 用历史数据按策略规则模拟交易，评估收益/风险 |
| EOD | End of Day，收盘后（15:00 后）数据处理 |
| 信号分 | 系统输出的 0–100 数值化关注度评分 |

## 2. 项目概述

### 2.1 产品定位
面向个人投资者 / 量化研究者的**本地化研究型交易辅助系统**：以资金流为核心，叠加价格与板块维度，提供「发现线索 → 回测验证 → 实时跟踪 → 日报提醒」的闭环。**本系统为研究与决策辅助工具，不构成投资建议，不自动下单。**

### 2.2 目标用户与使用场景

| 用户画像 | 核心诉求 | 典型场景 |
| --- | --- | --- |
| 个人量化研究者（主要） | 验证资金流因子有效性、做板块内选股 | 收盘后跑增量 → 看板块/个股排名 → 跑回测 → 读日报 |
| 资深操盘手 | 盘中跟踪主力流入与尾盘异动 | 盘中打开实时看板 → 观察尾盘资金强度 → 生成关注清单 |
| 架构/开发维护者 | 持续迭代、可追溯 | 维护 memory / TODO / 变更记录 |

### 2.3 业务目标（可度量）

| 编号 | 目标 | 度量指标 |
| --- | --- | --- |
| G1 | 完整覆盖目标板块 | 电网设备、天然气两板块成分股覆盖率 ≥ 95%，且每日自动更新 |
| G2 | 因子有效性可验证 | 回测输出因子 RankIC、IC 胜率、多空/多头超额收益，且可复现 |
| G3 | 数据持续可用 | 交易日增量拉取成功率 ≥ 98%（含自动重试后的成功率） |
| G4 | 实时可见 | 盘中资金流看板刷新延迟 ≤ 5 分钟 |
| G5 | 决策可用 | 每日收盘后自动产出信号清单 + AI 日报 |
| G6 | 可持续实施 | 全流程有 memory/TODO/变更记录，任意时点可接续开发 |

### 2.4 范围边界

**包含（In Scope）**
- A股行情（日线）与资金流（板块级 + 个股级）采集、存储、增量更新。
- 目标板块（电网设备、天然气）成分与归类。
- 资金流因子计算、4 类策略信号、回测引擎。
- 盘中实时快照与实时预测、WebSocket 推送。
- 精美的 Web 可视化（看板/对比/详情/回测报告/日报）。
- 调度、日志、监控、memory/TODO 工程化沉淀。

**不包含（Out of Scope，本期）**
- 实盘自动下单/券商接口对接（W）。
- 港股/美股/加密货币。
- 高频/Tick 级交易与做市。
- 多用户账号体系与权限（单机本地使用为主，云端为可选增强）。

### 2.5 约束（Constraints）

| 编号 | 约束 |
| --- | --- |
| C1 | 后端使用 **Python**（3.12），项目内使用独立虚拟环境 `.venv` |
| C2 | 前端不限技术，倾向 **纯 HTML5 + 现代 CSS + ECharts**，尽量免构建步骤 |
| C3 | 数据优先使用**免 Key 的公开数据源**（AkShare 口径）；MCP `mcp_stock-data` 作为高可用/备援数据源 |
| C4 | A股交易规则约束：**T+1**、涨跌停不可成交、交易成本（佣金/印花税/过户费）需计入回测 |
| C5 | 目标板块限定为 **电网设备** 与 **天然气**（可配置扩展） |
| C6 | 长期实施，必须持续维护 memory / TODO 文档 |

### 2.6 假设（Assumptions）
- 数据源接口在交易日可用；非交易日无增量（可跳过）。
- 板块分类采用东财口径（行业：电网设备；概念：天然气），成分股偶有调整，需定期刷新。
- 运行环境可访问公网（用于拉取数据与 CDN 静态资源）。

### 2.7 依赖（Dependencies）
- Python 运行时与依赖包（见 `requirements.txt`）。
- 数据源：AkShare（主）、`mcp_stock-data` MCP（备援/校验）。
- 前端依赖：ECharts、TailwindCSS（CDN 或本地静态）。
- 可选：Supabase（远程库）、LLM 服务（AI 日报）。

## 4. 功能需求（FR）

### 4.1 M1 数据采集（Data Ingest）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-1.1 | 支持**历史行情**批量拉取（目标板块成分股日线：开高低收、成交量额、复权） | M |
| FR-1.2 | 支持**板块资金流**拉取（行业资金流 / 概念资金流，今日/5日/10日） | M |
| FR-1.3 | 支持**个股资金流**拉取（超大单/大单/中单/小单净流入及占比，主力净流入） | M |
| FR-1.4 | 支持**板块成分股**获取（行业：电网设备；概念：天然气），并定期刷新 | M |
| FR-1.5 | 支持**指数行情**（如沪深300/上证指数）用于基准与相对收益 | S |
| FR-1.6 | 支持**实时行情快照**（盘中）与批量实时（用于尾盘/实时预测） | S |
| FR-1.7 | 数据源采用**适配器模式**，主源为 AkShare，备援为 `mcp_stock-data`，支持自动故障转移 | S |
| FR-1.8 | 采集具备**重试、限速、超时、熔断**保护，失败可观测 | M |
| FR-1.9 | 支持**辅助数据**（涨跌停池、北向、两融、龙虎榜、新闻等）按需拉取（可选增强） | C |

**输入**：目标板块列表、股票代码列表、日期区间、数据源配置。
**输出**：规范化后的原始数据集（落库 + 原始快照备份）。
**验收**：给定日期区间可拉取全部目标成分股行情与资金流，字段完整、无重复、失败有日志。

### 4.2 M2 数据存储（Storage）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-2.1 | 使用 **SQLite** 作为本地主存储（单文件、零运维）；可选 Supabase(Postgres) 作为远程副本 | M |
| FR-2.2 | 建立维度表与事实表：股票/板块/成分/行情/资金流/因子/信号/回测/任务水位 | M |
| FR-2.3 | 支持**幂等写入与去重**（唯一键 upsert），重复拉取不产生脏数据 | M |
| FR-2.4 | 记录**数据水位表**（每数据集的最后成功日期/时间），驱动增量拉取 | M |
| FR-2.5 | 保存**数据质量标记**（缺失、异常值、来源、抓取时间） | S |
| FR-2.6 | 提供**数据导出**（CSV/JSON/Parquet）与备份能力 | C |

**验收**：重复执行同一日采集任务，数据库行数不增加；水位表正确前移；可查询任意数据集最新可用日期。

### 4.3 M3 因子计算（Feature/Factor）

| 编号 | 因子 | 定义 | 优先级 |
| --- | --- | --- | --- |
| FR-3.1 | 主力净流入 | (超大单+大单)主动买入 − (超大单+大单)主动卖出 | M |
| FR-3.2 | 主力净流入占比 | 主力净流入 / 当日成交额 | M |
| FR-3.3 | 机构单趋势强度 | `mean(机构单净流入) / mean(|机构单净流入|)`，滚动窗口，取值 [-1,1] | M |
| FR-3.4 | 连续净流入天数 | 连续 N 日主力资金净流入的天数 | M |
| FR-3.5 | 尾盘资金流入强度 | 尾盘(14:30–15:00)净流入 / 全天成交额，及月度边际变化 | S |
| FR-3.6 | 情境-特征因子(IRCF) | 依「下跌日看小单卖出 / 上涨日看大单买入 / 大单作用于小市值」构建 | C |
| FR-3.7 | 中性化 | 行业、市值中性化处理，剔除高拥挤行业 | S |
| FR-3.8 | 因子版本化 | 因子口径变更需版本化并记录（可复现） | S |

**验收**：给定输入数据，因子计算可复现、无未来函数（严格使用 `t` 及之前数据），支持按股票/日期/板块查询。

### 4.4 M4 策略信号（Strategy）

| 编号 | 策略 | 概要 | 优先级 |
| --- | --- | --- | --- |
| FR-4.1 | 板块内主力资金强度排序 | 板块内按资金流强度排序，输出强弱榜单 | M |
| FR-4.2 | 持续性 + 股价未反应筛选 | 连续净流入≥N日、净流入占比>阈值、同期涨幅低、板块内排名前 X% | M |
| FR-4.3 | 板块间资金轮动 | 行业层面横向对比，输出轮动方向 | S |
| FR-4.4 | 情境-特征匹配 | 按涨跌情境切换大小单有效性规则 | C |
| FR-4.5 | 综合信号分与分级 | 输出 0–100 信号分 + 分级（强烈关注/关注/中性/回避） | M |
| FR-4.6 | 风险过滤 | 非 ST/退市风险、日均成交额>5000万、非涨跌停 | M |
| FR-4.7 | 解释性输出 | 每条信号给出触发的因子与理由（可解释） | S |

**信号规则（默认，可配置）**
```
信号 = "关注"，当且仅当满足：
1) 资金流：连续净流入天数 ≥ 3；主力净流入占比(5日均) > 板块中位数；超大单净流入占比 > 0
2) 股价：5日涨幅 < 板块中位数涨幅；股价 < 20日布林带中轨
3) 板块：所在板块位于行业资金流排名前 50%；板块拥挤度 < 历史 80% 分位
4) 风险：非 ST/退市风险；日均成交额 > 5000 万；当日非涨跌停
```

**验收**：对任选交易日，可产出结构化信号清单（含触发理由），且规则参数可外部配置。

### 5.1 数据实体与来源

| 编号 | 数据集 | 关键字段 | 频率 | 主来源 |
| --- | --- | --- | --- | --- |
| DR-01 | 股票基础信息 | 代码、名称、市场、行业、上市状态、ST 标记 | 低频/按需 | stock_info |

| DR-05 | 指数行情 | 指数 OHLC、量额 | 日 | `index_prices` |
| DR-06 | 板块资金流 | 板块、主力/超大/大/中/小净流入及占比 | 日（今日/5日/10日） | `stock_sector_fund_flow_rank` |
| DR-07 | 个股资金流 | 股票、各档净流入及占比、主力净流入 | 日 | `stock_fund_flow` |

| DR-11 | 回测结果 | 策略、参数、净值序列、指标 | 按需 | 系统计算 |
| DR-12 | 任务与水位 | 任务名、状态、开始/结束、水位日期 | 每次执行 | 系统记录 |
| DR-13 | 辅助数据(可选) | 涨跌停池、北向、两融、龙虎榜、新闻 | 日 | 对应接口 |

### 5.2 数据质量要求
- **完整性**：目标板块成分股覆盖率 ≥ 95%；关键字段非空率 ≥ 98%。
- **准确性**：数值与来源一致；异常值（如净流入占比绝对值 > 100%）需标记并人工复核。
- **唯一性**：`(股票, 日期)`、`(板块, 日期)`、`(因子, 股票, 日期, 版本)` 唯一。
- **时效性**：EOD 数据于收盘后 ≤ 30 分钟入库；盘中快照延迟 ≤ 5 分钟。
- **可追溯**：每条记录记录来源与抓取时间。

### 5.3 增量拉取策略
- 每数据集维护**水位表**（最后成功日期）。
- 采集时以 `(水位, 今日]` 为增量区间，按唯一键 **upsert**。
- 支持**补数**：可指定区间重跑，幂等覆盖。
- 失败重试后仍失败则记录并告警，不阻断其它数据集。

### 附录A：资金流指标定义（权威口径）
```
主力净流入      = (超大单主动买 + 大单主动买) − (超大单主动卖 + 大单主动卖)
主力净流入占比  = 主力净流入 / 当日成交额
机构单趋势强度  = mean(机构单净流入) / mean(|机构单净流入|)   ∈ [-1, 1]
连续净流入天数  = 连续满足 主力净流入 > 0 的天数
尾盘资金流入强度 = 尾盘(14:30–15:00)净流入 / 全天成交额
```
